# Super-Alpha Notes

## Goal

Make Relay Rift fun within 10 seconds, even without other players.

## What changed

- Instant Run creates a room, fills bot slots, and launches countdown.
- Mission contracts give players an immediate goal.
- Boss Rush and Rift Sprint add distinct reasons to replay.
- Focus Burst makes Shift more than movement: it can affect the ball.
- Boss cores create priority targets and stronger level identity.

## Design rule going forward

Every new system must answer one of these questions:

1. Does this make the first minute clearer?
2. Does this make the ball more expressive?
3. Does this create a cooperative or competitive decision?
4. Does this improve replayability without more setup?
